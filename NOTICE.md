# Provenance and contributor notice

PrevOccupAI-HAR-DL was implemented for the subject-disjoint muscleBAN
deep-learning HAR analysis led by Gonçalo Barros, with Sara Santos, Phillip
Probst, and Hugo Gamboa as study co-authors.

The current package is an independently structured implementation. Its
scientific design, dataset contracts, preprocessing reconstruction, and
classical comparator were informed by prior PrevOccupAI work. In particular,
Phillip Probst made substantial contributions to the original PrevOccupAI
repository and its methodological foundations. The prior repositories are
linked in the project README and retained as explicit provenance in the method
configuration files.

No raw participant data, processed participant arrays, device identifiers,
feature matrices, predictions, fitted weights, or serialized estimators are
distributed here.
